# Эмулятор языка оболочки ОС

## Описание

Эмулятор предназначен для работы в режиме CLI, имитируя сеанс shell в UNIX-подобной ОС. Он работает с образом виртуальной файловой системы, предоставленным в формате tar, без необходимости распаковки у пользователя.

## Конфигурация

Конфигурационный файл имеет формат JSON и содержит следующие параметры:
- **Путь к архиву виртуальной файловой системы.**
- **Путь к стартовому скрипту.**

Стартовый скрипт выполняет начальный список команд из файла при запуске эмулятора.

## Поддерживаемые команды

1. `ls` — вывод списка файлов и директорий.
2. `cd` — смена текущей директории.
3. `exit` — завершение работы эмулятора.
4. `mkdir` — создание новой директории.
5. `rev` — чтение содержимого файла и вывод его в обратном порядке.

## Запуск

Эмулятор запускается из командной строки с указанием пути к конфигурационному файлу:

```bash
python3 emulator.py --config config.json
```

## Тестирование

Все функции эмулятора покрыты тестами. Для каждой из поддерживаемых команд написано по 2 теста.
